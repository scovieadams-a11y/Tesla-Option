# Tesla Option

Tesla Option is an AI-powered trading platform supporting:

- Forex
- Metals
- Deriv Synthetic Indices
- AI Signal Scanner
- Automated Trading Bots
- Demo Account
- Live Account
- Investment Plans
- Wallet
- Admin Dashboard

## Technologies

Frontend
- Next.js
- React
- TypeScript
- TailwindCSS

Backend
- Node.js
- Express
- PostgreSQL
- JWT Authentication
- Socket.IO
